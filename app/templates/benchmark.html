{{ icon('alert-triangle', 18, 'text-amber-500') }} Run throughput sweep?

This takes over the machine for about .

  • Each model is loaded into a separate container that takes the GPUs for the duration. Whatever the server has resident will be competing for VRAM, or fail to load.
  • OpenWebUI requests will stall or fail throughout.
  • Nothing is written to models.ini. Settings are read from it, never changed.
  • Speculative decoding and the projector are not measured — llama-bench cannot use them. Expect lower numbers than the prompt suite for the same model.
  • You can stop at any time; the running container is killed and results so far are kept.
