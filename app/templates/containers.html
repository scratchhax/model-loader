Model Loader auto-discovers any container running ghcr.io/ggml-org/llama.cpp:* — no config change here needed. Just add a service to your compose file and docker compose up -d <service-name>. Templates below; edit the port and name, paste into your compose.

Keep the command router-only. Inference flags on the container command line (-ngl, -fa, -ctk, -ctv, -np, -sm) override models.ini rather than acting as defaults — a preset that disagrees is silently discarded. Set those per-model in the config form instead, and leave only --models-dir --models-preset --host --port --models-max here.
