{# The overview's two chart shapes, shared so every panel draws them the same way: a smooth filled sparkline for anything that moves over time, and a ring for anything that is a share of a whole. Colour comes in as a text-* class and is drawn with currentColor, so a caller states meaning (emerald, amber, red, a tenant's kind) and never repeats the drawing. Both take a stable id. The panels re-render every second; HTMX's settle step carries an element with the same id from its old attributes to its new ones, which is what lets the ring sweep and the colour fade instead of jumping. The sweep takes the whole second, linear, so it runs into the next reading rather than finishing early and pausing. `live` is the third shape: a time chart drawn in the browser by _live.html, every frame, from /api/v1/series. It scrolls continuously and its leading edge moves between readings, which a chart re-rendered by the server once a second cannot. hx-preserve keeps it across the swap. #} {% macro live(id, spec, h='h-12', color='') -%}
{%- endmacro %} {% macro area(cv, id, color, h='h-12') -%} {%- endmacro %} {# `color` is a text-* class; pass `stroke` (an rgb() from heat()) to colour by level instead. #} {% macro ring(id, pct, color, size='h-16 w-16', width=10, stroke=none) -%} {% set p = [[pct or 0, 0] | max, 100] | min %} {%- endmacro %}
